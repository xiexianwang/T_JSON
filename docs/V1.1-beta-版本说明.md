# LSS Video Manager V1.1-beta 版本说明

## 概述

本版本为 **V1.1 测试版**，主要针对 PTZ 云台角度数据通道和零点标定逻辑进行了重构，解决了角度显示与视频 OSD 不一致的问题。

## 本版本主要变更

### 1. 云台角度数据源切换
- **statPanAngle / statTiltAngle** 显示的数据源从串口服务器（Pelco-D）改为 **8089 端口（JSON 协议）**，与设备内部真实角度保持一致。

### 2. 零点标定重构
- 点击标定后，软件偏移量（offset）仅作用于 **转发给相机的 Pelco-D 数据**，使视频 OSD 显示偏移后的角度。
- 标定后立即向相机推送一次 0° 位置帧，OSD 即时更新，无需等待下一帧。

### 3. 串口数据转发修正
- 修复了 `PtzForwarder` 中原始帧覆盖偏移帧的 Bug，确保转发给相机（26 端口）的数据包含正确的偏移量。

### 4. 经纬度/角度引导
- `ptzMoveTo` 已集成偏移处理：输入的是偏移后坐标（与 OSD 一致），内部自动转换为物理角度后发送给转台。

### 5. 高度显示
- 设备高度为 0 时，UI 输入框自动清空，不再残留上次的值。
